Microservice Features & Capabilities

Watermark-Free Commercial Output

Every single generation request issued through this microservice enforces addWatermark: false inside the Adobe 3P parameters payload. The resulting images are clean, commercial-ready, and free of any Adobe Firefly corner badges or metadata overlays.

Multi-Provider Architecture

Access 20 leading frontier generation models through a single standardized REST API interface:

  • Google Gemini / Nano Banana Series: Gemini 3.1 (Nano Banana 2), Nano Banana 2.1, and Gemini 3 (Nano Banana Pro) with prompt adherence and typography.
  • OpenAI GPT Image Series: GPT Image 2.5 Sunburst (ultra-low cost: 5 credits), GPT Image 2.5 Flare, GPT Image 2, GPT Image 1.5, and GPT Image 1.
  • Black Forest Labs (FLUX): FLUX.2 [pro], FLUX1.1 [pro] Ultra Raw, FLUX1.1 [pro], FLUX.1 Kontext [max], and Kontext [pro].
  • Adobe Firefly Native: Firefly Image 4 (Free 10,000/day), Firefly Image 3 (Free), Firefly Image 4 Ultra, and Firefly Image 5 Preview.
  • Cinematic & Photoreal: Runway Gen-4 Image and HUMAIN Image 1.

Automated Local Archiving & Cloud CDN

Generated visuals are automatically polled from Adobe's worker queues (~8 to 12s), downloaded as lossless PNGs into ./output/, and served directly by the Express server under /output/*.png. The API also returns Adobe's direct presigned S3 CDN URL for cloud pipelines.

Zero-Friction Session Management

Using the companion Chrome extension, clicking Update & Sync Session while on firefly.adobe.com captures your active 24-hour Bearer token and sherlock session fingerprint and syncs them to port 5055. No manual token copying or credential entry required.

API Reference & Integration Guide REST v1

Authentication

All programmatic endpoints require authentication via header:

x-api-key: YOUR_MASTER_KEY

Or alternatively: Authorization: Bearer YOUR_MASTER_KEY

1. Generate Image (Default: GPT Sunburst, 5 cr)

POST /v1/images/generate

Generates an image via the serial execution queue (concurrency = 1, 5s cooldown).

curl -X POST http://localhost:5055/v1/images/generate \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_MASTER_KEY" \
  -d '{
    "prompt": "futuristic robotic samurai in neon rain, cinematic lighting, 8k",
    "modelId": "gpt-image-2-5-prism",
    "aspect": "3:4",
    "quality": "medium"
  }'

Response format (HTTP 200):

{
  "success": true,
  "prompt": "futuristic robotic samurai in neon rain...",
  "aspect": "3:4",
  "imageUrl": "/output/firefly_gpt-image-2.5-prism_1792939463396.png",
  "presignedUrl": "https://pre-signed-firefly-prod.s3-accelerate.amazonaws.com/images/...",
  "imagePath": "/app/data/output/firefly_gpt-image-2.5-prism_1792939463396.png",
  "model": "gpt-image/gpt-image-2.5-prism",
  "referencesAttached": 0,
  "latencyMs": 20253
}

2. Reference Image Upload & Multi-Reference Composition (Max 4)

POST /v1/storage/upload

Upload any base64 image or data URI to Adobe storage cluster and receive an asset ID:

curl -X POST http://localhost:5055/v1/storage/upload \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_MASTER_KEY" \
  -d '{
    "image": "data:image/png;base64,iVBORw0KGgo...",
    "mimeType": "image/png"
  }'

Attach up to 4 reference images directly in /v1/images/generate (by Asset ID, local file path, URL, or Base64):

curl -X POST http://localhost:5055/v1/images/generate \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_MASTER_KEY" \
  -d '{
    "prompt": "futuristic crystal flower hologram in dark void",
    "modelId": "clio-v4-standard",
    "referenceImages": [
      { "id": "95e1a214-0fc2-4f7b-bd65-102dd56a9785", "usage": "subject" }
    ]
  }'

3. Check Credit Balance

GET /v1/credits/balance

curl http://localhost:5055/v1/credits/balance \
  -H "x-api-key: YOUR_MASTER_KEY"

4. Service Status & Queue Health (Public)

GET /api/status

curl http://localhost:5055/api/status

5. Official Node.js SDK

import { Firefly } from "./sdk/index.js";

const firefly = new Firefly({
  baseUrl: "http://localhost:5055",
  apiKey: "YOUR_MASTER_KEY"
});

// Generate image
const result = await firefly.generate({
  prompt: "cyberpunk detective in rainy alleyway",
  aspect: "3:4"
});
console.log("Local image URL:", result.imageUrl);

6. Official Python SDK

from sdk.firefly import Firefly

firefly = Firefly(
    base_url="http://localhost:5055",
    api_key="YOUR_MASTER_KEY"
)

result = firefly.generate(
    prompt="futuristic hovercar over cyberpunk city",
    aspect="16:9",
    model_id="clio-v4-standard" # Free 0 cr
)
print("Image URL:", result["imageUrl"])

7. Model Context Protocol (MCP) for AI Agents

Connect your service directly to Antigravity, Claude Desktop, or Cursor via STDIO:

{
  "mcpServers": {
    "firefly": {
      "command": "node",
      "args": ["/home/app/fly-api/mcp/server.js"],
      "env": {
        "FIREFLY_API_URL": "http://localhost:5055",
        "FIREFLY_API_KEY": "YOUR_MASTER_KEY"
      }
    }
  }
}
